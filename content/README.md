# Content

This area will hold version-controlled MathKX learning content. At present it contains only one illustrative exercise definition used to explore the preliminary format.

As real content is introduced, the intended organization is:

```text
content/
  skills/       curriculum-independent mathematical skills and prerequisites
  exercises/    reusable exercise definitions
  curricula/    competency goals and mappings from curricula to skills
```

Empty placeholder directories have not been committed. Their exact file formats will be designed from real examples. Read [content contributor guidance](AGENTS.md), the [exercise capability model](../docs/architecture/exercise-capability-model.md), and the [preliminary exercise format](../docs/architecture/exercise-format.md) before adding content.
